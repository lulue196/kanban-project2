# KanbanFlow — Team Task Management System

KanbanFlow is a full-stack task management web application developed using **Next.js, TypeScript, and MongoDB**. The system allows users to organize tasks using a Kanban board, manage categories and team members, and view project statistics through a dashboard.

- TypeScript
- MongoDB
- REST API
- Recharts

## Main Features

- Kanban Board with TODO, DOING, and DONE status
- Create, view, edit, and delete tasks
- Create, view, edit, and delete categories
- Create, view, edit, and delete team members
- Assign categories and members to tasks
- Dashboard with task statistics and charts
- MongoDB database for persistent data storage

## Three CRUD Data Models

### 1. Tasks

Users can:
- Create tasks
- View tasks
- Edit tasks
- Delete tasks
- Change task status
- Assign a category and team member

### 2. Categories

Users can:
- Create categories
- View categories
- Edit categories
- Delete categories

### 3. Team Members

Users can:
- Create team members
- View team members
- Edit team members
- Delete team members

## REST API

### Tasks
- GET /api/tasks
- POST /api/tasks
- GET /api/tasks/:id
- PUT /api/tasks/:id
- DELETE /api/tasks/:id

### Categories
- GET /api/categories
- POST /api/categories
- GET /api/categories/:id
- PUT /api/categories/:id
- DELETE /api/categories/:id

### Team Members
- GET /api/members
- POST /api/members
- GET /api/members/:id
- PUT /api/members/:id
- DELETE /api/members/:id

## Application Usage

1. Create categories and team members.
2. Create a new task from the Kanban Board.
3. Assign a category and team member to the task.
4. Move tasks between TODO, DOING, and DONE.
5. Edit or delete existing records.
6. Open the Dashboard to view task statistics and charts.
